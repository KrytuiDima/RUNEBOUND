# RUNEBOUND — Production Codebase

## How to Play (Development)

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Start Server**:
   ```bash
   cd packages/server
   npm run build
   npm start
   ```
3. **Start Client**:
   ```bash
   cd packages/client
   npm run dev
   ```
4. **Gameplay**:
   - **Hold 'Q'**: Enter Drawing Mode.
   - **Mouse/Touch**: Draw a gesture on the screen.
   - **Release 'Q'**: Gesture is captured and sent for validation.
